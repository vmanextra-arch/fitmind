# FitMind — GitHub Pages

Статическая версия без сервера и ключей API. Профиль, планы, тренировки, дневники и расчёты работают в браузере. Чат и оценка еды через DeepSeek скрыты; исходный код сохранён. Данные не синхронизируются между устройствами: используйте экспорт/импорт в профиле. Не очищайте данные браузера без резервной копии.

Публикация: создайте публичный репозиторий, загрузите содержимое этой папки в корень (включая .github и .nojekyll). В Settings → Pages выберите Source: GitHub Actions. Workflow Publish FitMind опубликует сайт после загрузки на main. Либо загрузите все обычные файлы и assets/shared, затем выберите Deploy from a branch → main → /(root). Сайт работает и по адресу username.github.io/repository/.

Для локального просмотра: python -m http.server 4186. Открыть http://localhost:4186. Нельзя запускать двойным кликом по index.html: браузер блокирует ES-модули в file://.
